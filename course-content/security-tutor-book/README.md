# Zero to CEH: A Hands-On Daily Security Journal

This is the self-published book being built incrementally, day by day, from the `security-tutor` course. It's generated and maintained by the `course-book` Claude Code skill (`~/.claude/skills/course-book/SKILL.md`) — run it after each day's security-tutor session, alongside (not instead of) `course-social-post` and `course-video-writeup`.

## Directory structure

```
~/course-content/security-tutor-book/
├── README.md              ← this file
├── outline.md             ← chapter manifest: order, titles, status, diagrams
├── chapters/
│   ├── day01-ip-addressing-cidr.md
│   ├── day02-routing-and-arp.md
│   ├── ... (one file per day, zero-padded, kebab-case slug)
│   └── images/
│       ├── day01-cidr-breakdown.svg
│       ├── day02-routing-decision.svg
│       └── ... (simple SVG line-art diagrams referenced from chapters)
└── exports/
    ├── README.md                                  ← pandoc install instructions (see below)
    ├── <course-slug>-book-print-manuscript.md     ← generated by export mode
    └── <course-slug>-book.epub                    ← generated by export mode, if pandoc is available
```

## Regenerating exports (EPUB + print manuscript)

**pandoc availability check (run 2026-10-19):** `which pandoc` returned nothing — **pandoc is not installed** in this sandbox, and this skill does not attempt to install it (no sudo/apt access here, and tooling installs aren't forced per project convention). See `exports/README.md` for the exact copy-paste install command for your own terminal.

Once pandoc is installed on your machine, or if you're running this skill somewhere it's already available:

1. Invoke the `course-book` skill in **export mode** ("export the book to EPUB and print").
2. It will concatenate all `draft, good source fidelity` / `needs-review` / `final` chapters (in `outline.md` order) into:
   - `exports/security-tutor-book-print-manuscript.md` — a single Markdown manuscript with front matter (title page, copyright placeholder, TOC, chapters, about-the-author placeholder), conceptually formatted for a 6x9in KDP paperback trim. Actual page layout for the print PDF still happens in your own tool (Word, Vellum, Atticus, Affinity Publisher) — this file is the complete, ordered manuscript to import there, not a press-ready PDF.
   - `exports/security-tutor-book.epub` — built via `pandoc`, ready to upload to KDP's Kindle eBook flow (or convert further in Kindle Create).
3. See `~/.claude/skills/course-book/references/export-guide.md` for the exact pandoc invocation this skill uses, and KDP-specific notes (trim size, margins, cover art) that are documented but intentionally not automated.

## How to keep building this book

After finishing a security-tutor session for a new day, run the `course-book` skill for that day (chapter mode). It reads that day's `video-writeup.md`/`social-media-post.md` (richest source) and `progress.md` (authoritative status/terminology), drafts the chapter using the same template as Chapters 1-13, adds a diagram if one clearly helps, and updates `outline.md`. This is a separate, explicitly-invoked step — `security-tutor` itself never calls it automatically.
